# Phase 0 기록 — 아직 함정을 세기 전이다

2026-08-25. 이 문서는 접기 판정이 아니다. **함정을 세기도 전에 측정 장치가 다섯 번 틀린 기록**이다.

## 무엇을 하려 했나

공공기관 채용공고 스무 건을 손으로 읽고 함정 넷이 각각 몇 건에 나오는지 세려고 했다. 세기 전에 표본을 모아야 했고, 거기서 계속 걸렸다.

## 틀린 것 다섯

| 무엇이 틀렸나 | 어떻게 알았나 | 고친 방식 |
|---|---|---|
| 함정 어휘를 머리로 만들었다 | 추측한 일곱 중 넷이 36쪽 공고문에 0건 | 어휘를 문서에서 뽑고 `probe/phrases.json`에 이력을 남긴다 |
| 표집이 한쪽으로 쏠렸다 | 앞에서부터 받으니 스무 건 중 열다섯이 병원 | 기관당 한 건 상한 + 고정 시드로 쪽 순서를 섞는다 |
| 문서 종류가 섞였다 | 첨부 첫 PDF를 집어 직무기술서가 표본에 들어왔다 | 파일명 점수제. 직무기술서·서식·지원서는 음수 |
| 실패 하나가 수집을 죽였다 | 196쪽 타임아웃에 목표 20건이 6건에서 끝났다 | 재시도 두 번, 실패한 쪽 번호를 대장에 남긴다 |
| 한 낱말이 반대 뜻을 잡았다 | 「중복지원 불가」가 「가점 중복 배제」로 잡혔다 | 「중복」을 어휘에서 빼고 오탐 기록에 남긴다 |

## 세기 전에 나온 도메인 사실

**절반 이상은 애초에 기계가 읽을 물건이 아니다.** 공고 약 490건을 훑어 정규직 신입이 15건이었고, 그중 PDF 공고문이 붙은 것은 6건이다. 나머지는 첨부가 아예 PDF가 아니거나(4건), 붙은 PDF가 직무기술서·기준 안내였다(5건).

**공고문이 짧다.** 받은 여섯 건이 3·3·5·6·8·10쪽이다. 국가공무원 시험 공고 36쪽과는 다른 물건이다.

**텍스트 추출에서 띄어쓰기가 사라지는 문서가 있다.** 서울대학교병원 공고문은 `료기관에서재난대응, 필수의료등진료`처럼 나온다. 여러 낱말로 된 표현을 찾는 방식이 그 문서에서는 통하지 않는다.

## 함정이 실제로 어떻게 생겼나 (표본 여섯 건, n이 작다)

세지 않았고, 눈으로 본 것만 적는다.

- 충남대학교병원 p1 — `※ 응시자격은 공고 마감 기준으로 판단`. ※ 뒤에 붙어 있다
- 충남대학교병원 p2 — `□ 가산점 관련 증명서 … 1부. (미등록시 가점 미부여)`. 괄호 안에 있다
- 서울대학교병원 p2 — `임용예정일(2026. 3. 1.) 이전 게재예정에 …`. 괄호 안에 날짜 기준이 들어 있다

## 다음

표본을 스무 건에서 **세 건**으로 줄이기로 했다. 수집이 예상보다 비싸고, 그 비용을 계속 치르는 것보다 Studio를 실제로 태워보는 쪽이 먼저다. 접기 기준은 버리고 성격을 사례 연구로 바꾼다. 수집기는 남겨둔다 — n을 키울 때 다시 쓴다.
